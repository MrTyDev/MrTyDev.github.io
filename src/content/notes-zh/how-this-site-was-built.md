title: 這個網站是怎麼做出來的
summary: 為生成式 AI 課程而寫，與一個在我自己伺服器上運行的 AI 一起完成。
---

這個網站是我生成式 AI 課程的作業。我和 Claude Code 一起完成它，而那個工作階段就跑在託管這裡大部分專案的同一台家用伺服器上。

我先把履歷交給它，接著讓它在伺服器上四處看看，讀每個服務背後的程式碼和筆記，所以這裡的描述來自專案實際做的事，而不是我記得要說的事。它也在網路上搜尋了 Skarven 的新聞報導，並主動剔除了一篇其實是在講另一個團隊的文章。

第一版看起來就像把履歷貼到網頁上。我直接這麼說，於是我們用更清楚的想法重做：這是一個教電腦「看見」的人，所以網站應該長得像模型看到的畫面。

AI 也犯過錯，而且有些只有我能抓到：它找到的照片裡有三張是別隊的無人機，它也一度把我的深偽研究寫成在講準確率，而真正的重點是模型在看哪裡。每一次修正都記錄在作業的 AI 互動紀錄裡。

## 新增內容

所有內容都是 Markdown。新增一個專案就是在 `src/content/projects/` 加一個檔案，中文翻譯放在 `src/content/projects-zh/`。網站用 Astro 建置，每次推送到 GitHub 都會自動部署到 GitHub Pages。
